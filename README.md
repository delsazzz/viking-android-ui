# ⚔️ Viking Android UI

Aplicación Android desarrollada como práctica académica centrada en el diseño de interfaces de usuario, navegación entre pantallas y gestión de recursos gráficos mediante Android Studio.

El proyecto recrea una experiencia visual inspirada en la temática vikinga, prestando especial atención a la organización de layouts, componentes visuales y flujo de navegación dentro de una aplicación móvil.

---

# 📖 Descripción

Este proyecto fue desarrollado con el objetivo de profundizar en el desarrollo de interfaces Android utilizando XML y Activities.

La aplicación está compuesta por múltiples pantallas conectadas entre sí mediante navegación interna, simulando una experiencia completa para el usuario.

El foco principal del proyecto se encuentra en la construcción de la interfaz gráfica y la gestión de recursos visuales.

---

# 📱 Pantallas implementadas

La aplicación incluye diversas secciones conectadas mediante navegación interna:

* Pantalla principal.
* Sección de exploración.
* Pantalla de personajes.
* Pantallas de detalle.
* Menús de navegación.
* Secciones informativas.

---

# 🏗 Arquitectura

El proyecto sigue una arquitectura clásica basada en Activities.

```text
Pantalla Principal
        │
        ▼
Menús de Navegación
        │
 ┌──────┼──────┐
 ▼      ▼      ▼
Sección A
Sección B
Sección C
```

Cada pantalla dispone de su propio layout XML y su correspondiente Activity para gestionar la navegación y el comportamiento básico.

# 🚀 Cómo ejecutar el proyecto

## Requisitos

* Android Studio
* Android SDK
* Emulador Android o dispositivo físico

## Instalación

1. Clonar el repositorio.

```bash
git clone https://github.com/tu-usuario/viking-android-ui.git
```

2. Abrir el proyecto en Android Studio.

3. Sincronizar dependencias Gradle.

4. Ejecutar la aplicación en un emulador o dispositivo Android.
